How the starter model works

Version 2 uses recent completed matches from the selected competition to estimate each team’s goals scored/conceded and recent form, blends those with league averages, then applies a Poisson score model for 1X2, likely scores, over/under and BTTS. If there is insufficient team history, it clearly falls back toward a league baseline. It does not include confirmed lineups, injuries, tactics, weather or bookmaker odds.
